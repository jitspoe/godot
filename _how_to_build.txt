Open developer command prompt for vs 2019
scons p=windows tools=yes arch=x86 target=release_debug
(To try: arch=32, maybe that'll remove the double build?)

You can create a Visual Studio solution via SCons by running SCons with the vsproj=yes parameter, like this:
scons p=windows vsproj=yes

What I used:
scons p=windows tools=yes arch=x86 target=release_debug vsproj=yes

scons p=windows tools=yes arch=32 target=release_debug vsproj=yes -j10

scons p=windows tools=yes vsproj=yes dev_build=yes target=editor -j10

scons p=windows tools=yes vsproj=yes debug_symbols=yes target=editor -j10


For tracy builds (old tracy addon):
scons p=windows tools=yes vsproj=yes debug_symbols=yes target=editor tracy_enable=yes CCFLAGS="-fno-omit-frame-pointer -fno-inline -ggdb3" -j10
	Flags aren't recognized, so maybe just: scons p=windows tools=yes vsproj=yes debug_symbols=yes target=editor tracy_enable=yes -j10

For tracy builds (new godot built-in):
scons p=windows tools=yes vsproj=yes debug_symbols=yes target=editor profiler=tracy profiler_path=E:\projects\godot\godot_engine_tremble\modules\godot_tracy\tracy -j10
Note: This doesn't seem to put the full tracy command line in the visual studio project, and editing the project vcxproj file doesn't work because it's using godot.windows.editor.x86_64.generated.props

Windows release:
set "plat=x86_amd64" & scons p=windows arch=x86_64 target=template_release -j8


Linux release:
scons p=x11 target=release tools=no debug_symbols=no use_lto=yes -j8
If getting python errors:
/usr/bin/env python3 $(which scons) p=x11 target=release tools=no debug_symbols=no use_lto=yes -j8
